# 현장 점검표 — 폰툰 예인 협조제어 시험

- 작성: 충남대학교 자율운항시스템공학과 윤원근 교수
- 사용법: 인쇄해서 항목마다 `[ ]` 를 채움. **A 에서 J 까지 순서대로** 진행함
- 한 항목이라도 통과하지 못하면 **다음 단계로 넘어가지 않음**
- 실행 순서의 근거와 명령은 `docs/RUN_ORDER.md`, 증상별 조치는 `docs/DEBUG.md`

## A. 시험 전날 — 소프트웨어 (육상)

| | 항목 | 통과 기준 |
|---|---|---|
| `[ ]` | A1 | `bash run_all.sh` 전체 6 단계 PASS |
| `[ ]` | A2 | `out/SITL_RUN.json` 의 `"pass": true` · `ok 20/20` |
| `[ ]` | A3 | 평균 위치오차 ≤ 0.01 m (실측 기준 0.001 04 m) |
| `[ ]` | A4 | `tests/run_tests.py` 0 FAIL (실측 63 PASS) |
| `[ ]` | A5 | ONNX 대 sb3 `max|Δ| < 1e-5` (실측 9.090e-07) |
| `[ ]` | A6 | `CRC_EXTRA` 52502 = 123 · 52503 = 16 불변 |
| `[ ]` | A7 | 정책 파일 `out/ppo_sc3_final.onnx` 존재 (78 867 B) |
| `[ ]` | A8 | NUC 에 `nuc/` · `pontoon_rl/` · ONNX 배치 완료 |
| `[ ]` | A9 | NUC `PYTHONPATH` 에 두 경로 등록, `import` 확인 |
| `[ ]` | A10 | 비행로그 저장 공간 확보, NUC 시각 동기 확인 |

## B. 입력 경로 결정 (가장 먼저 닫아야 하는 항목)

| | 항목 | 통과 기준 |
|---|---|---|
| `[ ]` | B1 | `tools/sniff_mothership.py --port 14600 --seconds 30` 실행 |
| `[ ]` | B2 | 측정 결과를 기록: 메시지 id · 주기 · 송신 sysid |
| `[ ]` | B3 | 경로 확정 — PX4 표준(`--state-src px4std`) 또는 52501 |
| `[ ]` | B4 | 52501 을 쓰는 경우에만: 패치 적용 + 다이얼렉트 재생성 완료 |

  정하지 않은 상태로 다음 단계에 넘어가지 않음

## F. 안전 경로 시험 (추진기 통전 전)

| | 항목 | 통과 기준 |
|---|---|---|
| `[ ]` | F1 | `rc_on_off = 1` → 송신 τ 가 전부 0 |
| `[ ]` | F2 | `on_off = 0` → 송신 τ 가 전부 0 |
| `[ ]` | F3 | 입력 단절 0.5 s → τ=0 송신 확인 |
| `[ ]` | F4 | NaN/inf 주입 → 메시지 전체가 τ=0 으로 교체됨 |
| `[ ]` | F5 | 노드 종료 → τ=0 을 10 회 송신 후 소켓 종료 |
| `[ ]` | F6 | 터그가 마지막 값을 유지하는 특성을 시험 인원 전원이 인지 |

- ⚠️ **터그 Pixhawk 에 수신 타임아웃이 없음.** τ=0 을 보내는 것은 NUC 쪽 장치이고
  Wi-Fi 가 끊기면 그 τ=0 조차 도착하지 못함
